## 📌 Project Overview

Mushasha Budgeting App is a mobile application developed to help users manage their personal finances. The app allows users to track expenses, set budget goals, and analyse their spending behaviour.

---

## 🎯 Purpose

* Track income and expenses
* Improve financial management
* Help users stay within budget
* Provide spending insights

---

## ✨ Features

### 🔐 User Login

* Secure login using username and password

### 📂 Categories

* Create and manage expense categories

### 💸 Expense Entries

* Add expenses with:

  * Date
  * Start & end time
  * Description
  * Category

### 📸 Photo Support

* Attach images to expenses

### 🎯 Budget Goals

* Set minimum and maximum monthly spending

### 📊 Reports

* View expenses by date range
* View totals per category

### 💾 Data Storage

* Uses RoomDB (SQLite) for offline storage

---
